BLESSY — projeto para Vercel + GitHub
=====================================

TODOS os arquivos estão SOLTOS, sem nenhuma pasta. É isso que resolve o problema:
o GitHub aceita vários arquivos arrastados de uma vez, mas engasga com pastas.

ARQUIVOS OBRIGATÓRIOS
  index.html        a página
  support.js        precisa estar junto, no MESMO nível do index.html
  *.webp / *.avif   imagens
  video-1..4.mp4    vídeos dos círculos (opcionais: sem eles os círculos desaparecem)

COMO SUBIR
1. No repositório do GitHub: Add file -> Upload files.
2. Abra esta pasta, selecione TODOS os arquivos (Ctrl+A) e arraste para a área de
   upload. NÃO arraste a pasta — arraste os arquivos.
3. Commit changes.
4. Vercel -> Add New -> Project -> importe o repositório.
   Framework Preset: Other. Build Command e Output Directory: em branco.
5. Deploy.
